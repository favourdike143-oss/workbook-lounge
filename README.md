# Your Audiobook Companion

Help me build a library for my audiobook YouTube channel(self help audiobooks) where viewers get to download the workbook for each audiobook I release.  Attached is my YouTube profile picture "Untitled design (3).png" so use it for branding on the website. The layout should not be one of a simple one page landing page. It should have a home interface, and one more section where the workbooks can be displayed and downloaded only by navigation from the home interface. In the workbook section, Don't use any visual placeholders for the workbooks that are yet to be displayed. Just display the one available, and show the progress of the next workbook. The Attached pdf is the only available workbook. Create a similar workbook cover version using the main book cover IMG_20260920_091650.png
